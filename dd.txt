Agentic AI and Real Office Exporters for Word, PowerPoint, and Excel

This plan outlines the architecture and implementation steps to build a premium, multi-agent Agentic AI system for COXMOX.

Multi-Agent Office Pipeline

To achieve corporate-level document quality rather than simple chatbot output, we will implement a multi-agent workflow inside the dedicated `office_agent` and `search_agent` directories:

```mermaid

graph TD

    UserPrompt[User Prompt] --> PlannerAgent[1. Planner Agent]

    PlannerAgent -->|Task Breakdown & Outline| ResearchAgent[2. Research Agent]

    ResearchAgent -->|Web Search & Scraped Facts| OfficeAgent[3. Document/Spreadsheet/Presentation Agent]

    OfficeAgent -->|Draft Office Structure| DesignAgent[4. Design Agent]

    DesignAgent -->|Themes, Layouts, Image Ranking/Placement| ReviewAgent[5. Review Agent]

    ReviewAgent -->|Final Polished JSON Payload| UIRenderer[Frontend Workspace UI]

```

Planner Agent: Breaks down the user prompt into structural requirements (e.g. section count, layout ideas, spreadsheet design).

Research Agent: Decides if current information is needed. Runs search queries, reads web pages, and selects the most relevant, reliable facts.

Office Specialist Agents (Document / Spreadsheet / Presentation): Converts outline & facts into structured templates and raw data.

Design Agent:

PowerPoint: Handles theme selection, fonts, colors, layout styling, and animations. Executes the image search and download loop: searches for images, ranks them by relevance/quality, downloads the best, and places them in the slide content.

Word: Adds cover page, table of contents (TOC) draft, margins, headers, footers, citations, and reference structures.

Excel: Organizes the workspace into multiple sheets (Dashboard, Analysis, Raw Data) with clean gridlines, bold headers, cells, and formula calculations.

Review Agent: Performs self-correction, verifies that all requested files match the user prompt, removes placeholders, checks spelling, and returns clean, usable JSON payload.

Free, API-keyless scraping tools:

`web_search(query: str) -> List[Dict[str, str]]`: Scrapes text results from DuckDuckGo HTML search.

`web_scrape(url: str) -> str`: Scrapes page text and returns a cleaned summary.

`download_image(query: str, expected_context: str) -> str`: Scrapes DuckDuckGo Images, ranks them by relevance to `expected_context`, downloads the highest-ranking image, saves it to `agents-backend/static/images/`, and returns its local HTTP URL.
